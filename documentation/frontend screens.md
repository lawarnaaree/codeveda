# Frontend Screens

| # | Screen | Purpose | Requirements |
| --- | --- | --- | --- |
| 1 | Login / Register | User access | Validation, loading, errors, password visibility |
| 2 | Dashboard | Operational overview | Stock summary, low-stock alerts, recent activity |
| 3 | Products | Manage the catalog | Search, filters, CRUD, empty states |
| 4 | Product Details | Inspect a product | SKU, category, price, quantity, and status |
| 5 | Orders | Manage orders | Order lists, status, details, and totals |
| 6 | User Management | Administer staff | Roles, permissions, active/inactive states |
| 7 | Notifications | Review updates | Low stock, order updates, real-time updates |
